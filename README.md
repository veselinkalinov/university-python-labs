### 📖 About
This repository documents my progress through the **Introduction to Python** course at the **Technical University of Sofia**. 

It serves as a comprehensive archive of laboratory exercises, homework assignments, and algorithmic implementations designed to build a strong foundation in software engineering and computational logic, specifically tailored for the university's engineering curriculum.

### 🧠 Key Concepts Covered
* **Advanced Data Structures:** Deep dives into Lists, Tuples, Sets, and Dictionaries.
* **Modular Programming:** Function definition, scope, and recursive logic.
* **Object-Oriented Programming (OOP):** Implementation of Classes, Methods, and Inheritance.
* **Error Handling:** Using `try/except` blocks for robust code execution.
* **File I/O:** Reading and writing data for persistent storage.
* **Mathematical Modeling:** Solving engineering-related problems using Python logic.
